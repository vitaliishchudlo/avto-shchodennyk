# Auto Fuel Tracker Bot

Telegram-бот українською мовою для обліку заправок і витрат на пальне.

Користувач додає заправки через діалог у чаті — бот зберігає дані, рахує витрату палива, вартість пробігу та показує статистику. Підтримується кілька автомобілів на одного користувача.

## Можливості

- додавання заправки (пробіг, літри, ціна, тип пального, АЗС, примітки)
- історія заправок з посторінковим переглядом
- статистика: витрата, вартість пробігу, загальні витрати
- кілька авто: додавання, перейменування, перемикання, видалення
- експорт історії в CSV
- налаштування валюти та відображення історії

## Команди

| Команда | Дія |
|---------|-----|
| `/start` | головне меню |
| `/add` | додати заправку |
| `/history` | історія заправок |
| `/stats` | статистика |
| `/last` | остання заправка |
| `/delete_last` | видалити останній запис |
| `/export` | експорт CSV |
| `/help` | довідка |

## Технології

Python · [aiogram](https://docs.aiogram.dev/) 3 · SQLite · python-dotenv
