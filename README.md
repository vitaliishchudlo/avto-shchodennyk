# Auto Fuel Tracker Bot

Telegram-бот українською мовою для обліку автомобільних заправок і витрат на пальне.

## Можливості

- Покрокове додавання заправки через FSM
- Історія заправок з пагінацією
- Статистика: витрата, вартість пробігу, загальні витрати
- Експорт історії в CSV
- Налаштування: назва авто, валюта

## Вимоги

- Python 3.12+
- Telegram-акаунт

## 1. Створення бота через BotFather

1. Відкрий Telegram і знайди [@BotFather](https://t.me/BotFather).
2. Надішли команду `/newbot`.
3. Введи назву бота (наприклад: `Auto Fuel Tracker`).
4. Введи username бота (має закінчуватися на `bot`, наприклад: `my_fuel_tracker_bot`).
5. BotFather надішле повідомлення з **токеном** — збережи його.

## 2. Отримання BOT_TOKEN

Токен виглядає приблизно так:

```
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

Це секретний ключ — не публікуй його в репозиторії.

## 3. Створення файлу `.env`

Скопіюй приклад і встав свій токен:

```bash
copy .env.example .env
```

Відредагуй `.env`:

```
BOT_TOKEN=твій_токен_від_BotFather
```

## 4. Встановлення залежностей

```bash
pip install -r requirements.txt
```

## 5. Запуск бота

```bash
python bot.py
```

Якщо все налаштовано правильно, у консолі з'явиться повідомлення `Бот запущено`.

## Команди бота

| Команда | Опис |
|---------|------|
| `/start` | Головне меню |
| `/add` | Додати заправку |
| `/history` | Історія заправок |
| `/stats` | Статистика |
| `/last` | Остання заправка |
| `/delete_last` | Видалити останній запис |
| `/export` | Експорт CSV |
| `/help` | Довідка |

## Структура проєкту

```
bot.py                  — точка входу
config.py               — конфігурація
database.py             — SQLite + aiosqlite
handlers/               — обробники команд
keyboards/              — inline-клавіатури
services/               — розрахунки та CSV
states/                 — FSM-стани
requirements.txt
.env.example
```
